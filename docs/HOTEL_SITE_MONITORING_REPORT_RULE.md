# BELEK NY: отчет о доступности официальных сайтов отелей

Статус: обязательное правило для каждого трехчасового мониторинга.

Каждый запуск до или параллельно с проверкой цен должен проверить доступность всех официальных сайтов из `data/hotel-site-links.json`.

Проверка сайта не является блокирующим условием для мониторинга цен. Если официальный сайт одного или нескольких отелей не отвечает, мониторинг должен продолжиться по всем остальным разрешенным источникам и завершить расчет ценовой дельты.

В итоговом отчете запуска обязательна строка состояния сайтов:

- `Сайты отелей: 10/10 доступны`, если открылись все 10;
- `Сайты отелей: недоступны <отель>: <адрес>; ...`, если есть сбои.

Если сайт отвечает перенаправлением на устойчивый официальный адрес того же отеля, канонический адрес нужно обновить в `data/hotel-site-links.json` при следующей содержательной публикации. Если перенаправление ведет на другой объект, агрегатор или нерелевантную страницу, ссылка считается ошибочной и должна быть исправлена до публикации карточки.

Недоступность сайта сама по себе не меняет цену, стрелку цены, рейтинг или рекомендации. Она попадает только в отчет мониторинга и в техническое состояние качества источников.

Публикация в прод по-прежнему разрешена только по реальной содержательной дельте согласно `docs/DELTA_ONLY_PRODUCTION_POLICY.md`.
