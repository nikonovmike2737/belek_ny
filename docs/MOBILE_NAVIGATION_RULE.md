# BELEK NY: мобильная навигация

Статус: обязательное правило для мобильной версии сайта.

## Бургер-меню

На ширине мобильного экрана основная навигация в шапке скрывается и заменяется кнопкой бургер-меню в правом верхнем углу шапки.

Шапка остается закрепленной при прокрутке. Кнопка меню является частью закрепленной шапки и остается доступной во время прокрутки страницы.

По нажатию кнопка открывает меню со ссылками на основные разделы страницы. Повторное нажатие закрывает меню. Выбор любого раздела также закрывает меню.

## Навигация по разделам

Мобильное меню содержит ссылки на разделы:

- Рейтинг;
- Карточки;
- Номера;
- Доплаты;
- Еда;
- Выбор.

Ссылки ведут к тем же идентификаторам разделов, что и навигация на большом экране.

## Положение раздела после перехода

Переход по якорной ссылке не должен помещать начало раздела под закрепленную шапку.

Для страницы задается отступ прокрутки не меньше фактической высоты шапки с небольшим запасом. Для самих целевых разделов задается такой же безопасный отступ. После перехода заголовок и начало раздела должны быть полностью видимы непосредственно под шапкой.

## Поведение и доступность

Кнопка меню должна иметь `aria-expanded`, `aria-controls` и понятную подпись для экранного диктора. Меню закрывается после выбора раздела, по Escape и при переходе с мобильной ширины на большой экран.

При открытом меню шапка не должна перекрывать содержимое самого меню. Меню открывается непосредственно под строкой шапки.

## Печать и PDF

Бургер-кнопка и мобильное меню относятся только к веб-интерфейсу и не должны появляться в печатной версии или PDF.
