# Реализация: кнопки карточки отеля

Референс поведения: публичный театральный гид `https://theatreguide.ru`.

Для карточек отелей применяется тот же принцип: в свернутом состоянии две кнопки в нижней строке, слева `Подробнее`, справа `Сайт отеля`. При открытии подробностей нижняя строка повторяется внизу раскрытого содержимого, но левая кнопка меняется на `Свернуть`. Правая кнопка остается `Сайт отеля` и открывает официальный сайт соответствующего отеля в новой вкладке.

Канонические URL и проверка соответствия конкретному отелю описаны в `data/hotel-site-links.json` и `docs/HOTEL_CARD_ACTIONS_AND_SITE_LINK_QA.md`.

Языковая версия официального сайта выбирается не один раз навсегда, а проверяется при каждом трехчасовом запуске. Порядок жесткий: RU -> EN -> DE -> TR. Сначала используется русская версия. Если она недоступна, проверяется английская; затем немецкая; затем турецкая. В карточку ставится первая работающая официальная версия именно этого отеля. Если выбранный язык меняется, это неценовая дельта URL и может быть опубликована без изменения цен, стрелок и времени обновления цен.

Если ни одна допустимая языковая версия не работает, сохраняется последний подтвержденный официальный адрес, проблема попадает в отчет мониторинга, а проверка цен продолжается по другим разрешенным источникам.
