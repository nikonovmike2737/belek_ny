# BELEK NY: Hotel Ranking Criteria

**Status:** CURRENT  
**Effective from:** release `20260912T191617Z`  
**Scope:** ranking and shortlist for 25.12.2026-03.01.2027.

This document is the source of truth for the three additional hotel-fit criteria introduced by explicit user instruction. It supplements, rather than replaces, the existing trip criteria.

## 1. Beach line and direct beach access

This is a high-weight criterion.

- Confirmed first line/direct access to the hotel's own or private beach preserves the existing base score. It is treated as a strong baseline expectation, not as an additive bonus.
- A hotel that is not on the first line or lacks direct beach access receives **-0.5 points**.
- The absence of first-line/direct beach access must also be stated explicitly in `Риски и ограничения`.
- Unclear evidence does not become a penalty until the absence is confirmed.

For the current 15-hotel set, first-line/direct-beach evidence is applied per hotel. Any confirmed absence must still be shown as a risk and -0.5 penalty.

## 2. Territory size

Territory is useful for this trip because a larger resort gives the group more space to walk and spend time outside the room. This criterion is **non-blocking**.

Adjustment:
- below 80,000 m²: `0`;
- 80,000-119,999 m²: `+0.1`;
- 120,000 m² or more: `+0.2`.

A smaller territory is not a standalone risk and does not disqualify a hotel.

## 3. Distinctive extra entertainment

Distinctive additional entertainment beyond the standard resort set is **non-blocking** and may add up to `+0.1`.

Examples include a genuinely separate attraction or activity that materially broadens the family's stay. Standard pools, kids club, generic animation, billiards or bowling do not automatically earn a bonus.

No double counting: if the same attraction is already a material driver of the base score, no second bonus is added.

Current examples:
- Bellis: zoo + horse-riding club -> `+0.1`;
- Rixos Park: The Land of Legends is already reflected in the base score -> `0` additional;
- Xanadu: Fancyland is already reflected in the base score -> `0` additional;
- Limak Atlantis: bowling is treated as a standard paid leisure option -> `0` additional.

## 5. Bellis interpretation

Bellis rises from `8.9` to `9.2`:
- `+0.2` for its 135,000 m² territory;
- `+0.1` for the zoo and horse-riding club;
- no beach bonus or penalty because first-line/direct beach access is treated as a high-weight baseline.

Bellis remains the control benchmark for the replacement decision rather than a replacement candidate itself.

## 6. Evidence rule

Use official hotel facts first. A current reputable secondary source may be used only where the official source does not publish the specific metric and the hotel identity is unambiguous. Unverified territory or beach claims do not change the score.

The public HTML must show the criteria transparently. Public risks must explicitly flag any future hotel that is confirmed not to be first-line/direct-beach.
