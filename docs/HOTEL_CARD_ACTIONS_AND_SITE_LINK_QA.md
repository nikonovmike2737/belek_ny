# BELEK NY: действия карточки отеля

Статус: CURRENT. Обязательное правило для HTML, mobile и QA перед публикацией.

Этот документ синхронизирован с фактическим prod и последней прямой командой пользователя. Более старые двухкнопочные и compare-варианты считаются устаревшими.

## 1. Три действия

Внизу каждой из 10 карточек ровно три действия в одной горизонтальной строке.

Закрытая карточка:

`Подробнее | Отзывы | Сайт отеля`

Открытая карточка:

`Свернуть | Отзывы | Сайт отеля`

Порядок фиксирован:

1. слева inline details toggle;
2. по центру TripAdvisor Reviews;
3. справа официальный сайт отеля.

Все три подписи должны помещаться в одну строку. На ширине 390 px действия остаются в одной горизонтальной строке без обрезания текста.

## 2. Подробнее / Свернуть

`Подробнее` раскрывает подробную часть той же карточки. `Свернуть` закрывает её.

По общему Editorial & Communication Canon неопределённый CTA `Подробнее` обычно нежелателен, но для этого inline toggle он является закреплённым продуктовым исключением по прямой команде пользователя. Не переименовывать без новой прямой команды.

## 3. Отзывы

`Отзывы` открывает страницу конкретного отеля в TripAdvisor, предпочтительно русскую версию.

Обязательно:

- ссылка относится к тому же отелю, что карточка;
- открывается в новой вкладке;
- `target="_blank"`;
- `rel` содержит `noopener noreferrer`;
- пользовательская подпись остаётся `Отзывы`;
- внутреннее название сервиса можно показывать логотипом, но не перегружать подпись техническими деталями.

## 4. Сайт отеля

`Сайт отеля` открывает официальную страницу именно этого отеля в новой вкладке.

Обязательно:

- точная hotel identity;
- `target="_blank"`;
- `rel="noopener noreferrer"`;
- языковой приоритет RU -> EN -> DE -> TR по `docs/HOTEL_SITE_LANGUAGE_PRIORITY_RULE.md`;
- не подставлять агрегатор, поставщика, другой объект сети или общую страницу бренда, если доступна страница конкретного отеля.

Канонический список официальных ссылок хранится в `data/hotel-site-links.json`.

## 5. Compare запрещён

Compare полностью удалён из текущего продукта. Без новой прямой команды пользователя не должно быть:

- кнопки `Сравнить`;
- compare dock;
- compare modal/dialog;
- compare state;
- compare-specific JS;
- скрытого восстановления старого flow.

Старые исторические документы могут упоминать compare только как прошлое состояние, но текущие правила и код не должны требовать его наличия.

## 6. PDF

Интерактивная строка действий относится к web и не должна создавать бессмысленные кнопки в PDF. В печатной версии раскрытые сведения показываются как обычный контент без `Подробнее/Свернуть`, `Отзывы` и `Сайт отеля`.

## 7. Проверка перед публикацией

Для всех 10 карточек проверить:

1. закрытое состояние: `Подробнее | Отзывы | Сайт отеля`;
2. открытое состояние: `Свернуть | Отзывы | Сайт отеля`;
3. ровно три действия и правильный порядок;
4. `Отзывы` ведут на TripAdvisor конкретного отеля;
5. `Сайт отеля` ведёт на официальный сайт конкретного отеля;
6. обе внешние ссылки используют safe new-tab attributes;
7. compare отсутствует;
8. открытие одной карточки не ломает остальные;
9. 390 px сохраняет одну строку действий;
10. PDF не показывает интерактивную строку действий.
