# BELEK NY: приоритет русского языка для сайтов отелей

Статус: обязательное правило для кнопок `Сайт отеля`, трехчасового мониторинга и проверки перед публикацией.

## Главное правило

Если официальный сайт конкретного отеля предлагает русскую версию, кнопка `Сайт отеля` должна открывать русскую страницу именно этого отеля.

Приоритет ссылок:

1. Русская официальная страница конкретного отеля.
2. Если русской версии у официального сайта нет, устойчивая официальная страница конкретного отеля на другом языке.
3. Общая страница сети допустима только когда отдельной страницы конкретного отеля не существует.

Нельзя заменять официальный сайт агрегатором, поставщиком, страницей другого отеля той же сети или нерелевантной страницей бренда.

## Источник истины

Канонический список хранится в `data/hotel-site-links.json`.

Для каждой записи хранятся:

- точное название отеля;
- канонический URL;
- подтверждение соответствия URL конкретному отелю;
- наличие русской версии;
- предпочтительный язык;
- подтверждение выбранной языковой версии.

Если `russian_available=true`, обязательны `preferred_language=ru`, `language_verified=true` и русская версия URL.

## Проверка каждые три часа

Каждый запуск мониторинга проверяет не только доступность канонического URL, но и то, что:

- адрес по-прежнему ведет на официальный сайт нужного отеля;
- если русская версия существует, каноническая ссылка открывает ее;
- обычное перенаправление не уводит на другой объект или агрегатор.

Если русская ссылка временно недоступна, но сайт отеля на другом языке работает, мониторинг цен не останавливается. В отчете нужно отметить проблему ссылки. Нельзя молча заменить русскую ссылку на постоянную английскую или турецкую, если русская версия по-прежнему существует.

## Публикация

Исправление языка ссылки является содержательной дельтой URL и может быть опубликовано в прод. Это не ценовая дельта: `previous_price_update_at`, `current_price_update_at`, цены и стрелки изменения цены не меняются.

Если новых изменений ссылок или данных нет, действует правило `NO DELTA = NO WRITE = NO COMMIT = NO DEPLOY`.
