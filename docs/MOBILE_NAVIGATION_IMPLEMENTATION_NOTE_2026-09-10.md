# Реализация мобильной навигации

Требование пользователя: на мобильной версии добавить закрепленное бургер-меню в правой части шапки, перенести в него навигацию по основным разделам и обеспечить переход к разделам без перекрытия их начала шапкой.

Каноническое правило поведения хранится в `docs/MOBILE_NAVIGATION_RULE.md`.
